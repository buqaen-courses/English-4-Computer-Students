# Technical Writing: From Code to Communication

**Course Theme:** The Art of Technical Communication

**Short Description:**
Transform complex technical concepts into clear, accessible documentation that serves developers, users, and stakeholders. Through practical exercises and real-world examples, you'll master the craft of technical writing that actually gets read and used.

**Learning Outcomes:**
- Write clear, scannable documentation for different audiences
- Create comprehensive READMEs, API docs, and installation guides
- Design error messages and code comments that help rather than hinder
- Apply documentation tools and processes for scalable content creation

**Sample Activities:**
- **README Makeover Challenge:** Transform sparse project documentation into professional, user-friendly guides
- **Error Message Redesign:** Rewrite cryptic error messages to be helpful and actionable
- **API Documentation Workshop:** Create complete documentation for a sample API
- **Code Comment Audit:** Review and improve commenting practices in real codebases

**Suggested Resources:**
- GitHub README and documentation templates
- "The Elements of Style" by Strunk & White (clarity principles)
- Documentation tools: MkDocs, Sphinx, JSDoc
- Real-world examples: Stripe API docs, React documentation, AWS guides
