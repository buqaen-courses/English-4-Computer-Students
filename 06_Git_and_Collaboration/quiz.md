# Git Collaboration Mastery Quiz

**Git Workflow Scenarios:**

1. **The Hot Fix Emergency:** Your production app has a critical security vulnerability. Users are panicking. How do you coordinate with your team to deploy a fix using Git and GitHub while minimizing downtime?

2. **The Feature Branch Dilemma:** You've been working on a major feature branch for 3 weeks. Meanwhile, main branch has evolved significantly. How do you safely merge your work without breaking the application?

3. **The Lost Commit Mystery:** A team member accidentally deleted an important commit. How do you help recover it using Git's reflog and other recovery mechanisms?

**Pull Request & Code Review Challenges:**

4. **The Massive PR Problem:** A junior developer submits a 50-file pull request with the description "Fixed some bugs." How do you approach reviewing this PR constructively?

5. **The Conflicting Feedback:** During code review, two senior developers give contradictory advice on the same code change. How do you help the author navigate this situation?

6. **The Urgent Hotfix:** A production issue needs immediate fixing, but your standard review process requires 24 hours. How do you balance speed with quality assurance?

**Issue Management Scenarios:**

7. **The Vague Bug Report:** A user reports "The app crashes sometimes" with no additional details. How do you guide them to provide actionable information for debugging?

8. **The Feature Request Flood:** Your open-source project receives 20 feature requests in one week. How do you prioritize and organize them effectively?

9. **The Duplicate Issue Dilemma:** Two users report the same bug with different severity levels. How do you consolidate these reports while keeping stakeholders informed?

**Team Communication Challenges:**

10. **The Remote Team Coordination:** Your team is distributed across 8 time zones. How do you ensure effective asynchronous communication for complex code changes?

11. **The Knowledge Transfer:** A key team member is leaving. How do you use Git and documentation to preserve their institutional knowledge?

12. **The Onboarding Challenge:** A new developer joins your team. How do you use GitHub's features to help them get up to speed quickly?

**Branching and Release Strategy:**

13. **The Release Branch Decision:** Your team ships updates monthly. How do you decide between GitFlow's release branches versus GitHub Flow's direct-to-main approach?

14. **The Experimental Feature:** You want to add a potentially disruptive feature that might be reverted. How do you implement this using Git's branching capabilities?

**Conflict Resolution & Recovery:**

15. **The Merge From Hell:** Two developers worked on the same file simultaneously, creating complex merge conflicts. How do you guide them through resolution?

16. **The Revert Situation:** After deploying a feature, critical bugs emerge. How do you safely revert the changes while preserving the team's work?

**Open Source Collaboration:**

17. **The First Contribution:** A newcomer wants to contribute to your open-source project. How do you structure the process to be welcoming yet maintain code quality?

18. **The Maintainer's Dilemma:** Your popular open-source library has 50+ open pull requests. How do you manage this volume while staying responsive to contributors?

**CI/CD Integration:**

19. **The Failing Pipeline:** Your CI pipeline fails after a recent merge. How do you coordinate between developers to identify and fix the issue quickly?

**Cultural and Professional Development:**

20. **The Code Review Culture:** How would you foster a positive code review culture in a team that currently avoids giving feedback due to fear of conflict?
