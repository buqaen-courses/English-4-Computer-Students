# Cybersecurity & Privacy

Short description:
Vocabulary and report-writing for vulnerabilities, exploits, encryption, and authentication.

Learning outcomes:
- Use correct terms when describing a vulnerability.
- Draft a concise security advisory or summary.

Sample activities:
- Read a CVE summary and rewrite it in clear English.
- Create a short advisory for a hypothetical vulnerability.

Suggested resources:
- OWASP top 10 summaries
- Intro articles on encryption and authentication
