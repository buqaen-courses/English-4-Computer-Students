## Week 1 — Core Systems & Programming (sample design)

Main article / primary reading:
- Title: "Memory Management Basics" (short blog/tutorial or selected excerpt from "Operating Systems: Three Easy Pieces")
- Link / source: https://pages.cs.wisc.edu/~remzi/OSTEP/ (choose the short chapter on memory)
- Rationale: introduces `runtime`, `memory allocation`, and `garbage collection` in a compact, accessible format.

Glossary (key terms):
- compiler — program that translates source code to machine code or intermediate code.
- runtime — the environment where a program executes; includes libraries and runtime support.
- process — an instance of a running program with its own memory space.
- thread — a lightweight sequence of execution within a process that may share memory.
- memory management — techniques for allocating, freeing, and organizing memory.
- stack — region for function call frames and local variables.
- heap — region for dynamic allocation at runtime.
- garbage collection — automatic memory reclamation technique used in some runtimes.
- segmentation / paging — basic memory protection and virtualization mechanisms.

Quick quiz (5):
1. What does a compiler do? (short answer)
2. Which is shared between threads in the same process: stack or heap? (MCQ)
3. True/False: A process always contains exactly one thread.
4. Match: stack / heap — (a) dynamic allocation (b) call frames
5. Short: Define "runtime" in one sentence.

Comprehension & discussion questions:
- Explain in your own words the difference between a process and a thread.
- Why is memory management important for program correctness and performance?
- How does garbage collection change the programmer's responsibilities?
- Give an example of a runtime error caused by incorrect memory use and describe how to debug it.

Homework:
- HW1: Read the selected OSTEP memory chapter and write a 150–200 word summary (due next class).
- HW2: Take a small code snippet (provided) that leaks memory or misuses memory; write a README paragraph explaining the bug and how to fix it.
- HW3 (optional): Prepare a 3-slide mini-presentation explaining one glossary term with an example.

Assessment checklist (to complete after session):
- [ ] Main article assigned and link posted to students
- [ ] Glossary handed out (or included in LMS)
- [ ] Quiz created and sample answers prepared
- [ ] Comprehension questions discussed in class
- [ ] Homework assigned with due date
