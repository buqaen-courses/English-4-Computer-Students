# Terminal Tales: Command Line Adventures

**Your CLI Journey:**

1. **Terminal Awakening:** What's your most memorable command-line success or failure? What did you learn from the experience?

2. **GUI vs CLI Mindset:** How has learning the command line changed how you think about computers compared to graphical interfaces?

3. **Automation Discovery:** What's the most repetitive task you've automated with a script? How has this changed your workflow?

**Core Command Line Skills:**

4. **File System Navigation:** Explain the difference between absolute and relative paths with examples. When would you use each?

5. **Piping Power:** Design a command pipeline that finds all Python files in a project, counts lines of code in each, and shows the top 5 largest files.

6. **Process Investigation:** You're debugging a slow application. What commands would you use to identify resource usage and potential bottlenecks?

**Scripting Craft:**

7. **Error Handling Design:** Write a bash script that safely copies a file and provides meaningful error messages if the operation fails.

8. **Argument Processing:** Create a script that accepts multiple file names as arguments and performs a batch operation (like renaming or compressing).

9. **Conditional Logic:** Design a script that checks system resources (disk space, memory) and sends alerts when thresholds are exceeded.

**Git Workflow Integration:**

10. **Repository Management:** You're working on a feature branch. Walk through the commands you'd use to create, work on, and merge the branch.

11. **Conflict Resolution:** Describe how you'd handle a merge conflict in Git using command-line tools.

12. **History Investigation:** How would you use Git commands to find when a particular bug was introduced?

**Networking and Remote Work:**

13. **SSH Mastery:** Explain how you'd set up SSH key authentication for passwordless access to multiple servers.

14. **File Transfer Scenarios:** Compare scp, rsync, and wget for different file transfer needs. When would you choose each?

15. **Network Diagnostics:** A website is down. What command-line tools would you use to systematically diagnose the issue?

**System Administration:**

16. **Log Analysis:** Design a command pipeline to analyze web server logs, finding the most common errors and their frequency.

17. **Package Management:** You're setting up a new development environment. Walk through the commands to install essential tools and verify installations.

18. **Backup Automation:** Create a script that performs automated backups with rotation and error handling.

**Advanced Techniques:**

19. **Text Processing Pipeline:** Build a complex command that processes a CSV file, filters data, performs calculations, and generates a report.

20. **Cron Job Setup:** How would you set up automated tasks using cron for system maintenance scripts?

**Security and Best Practices:**

21. **Secure Scripting:** What security considerations should you include when writing scripts that handle sensitive data?

22. **Command History Audit:** How can you use command history and auditing to improve your command-line efficiency and avoid repeating mistakes?

**Tool Integration:**

23. **Docker CLI:** Explain how you'd use command-line tools to build, run, and manage a containerized application.

24. **Cloud CLI Tools:** How would you use AWS CLI or Azure CLI to manage cloud resources from the command line?

**Troubleshooting and Debugging:**

25. **Script Debugging:** Your script is failing silently. What techniques would you use to add debugging and identify the issue?

26. **Performance Profiling:** How would you use command-line tools to identify which processes are consuming the most resources?

**Learning and Mastery:**

27. **Skill Development Plan:** Create a 30-day plan to improve your command-line proficiency, including specific commands and scripts to learn each week.

28. **Teaching CLI Skills:** How would you explain the benefits of the command line to someone who only uses graphical interfaces?

**Real-World Applications:**

29. **DevOps Pipeline:** Design a simple CI/CD pipeline using command-line tools that builds, tests, and deploys a web application.

30. **Data Processing Workflow:** Create a command-line workflow that downloads data, processes it, generates visualizations, and cleans up temporary files.

**Instructor Notes:**
- Encourage students to practice commands in safe environments
- Emphasize that command-line skills build gradually through regular use
- Connect CLI concepts to broader programming and system administration skills
- Help students understand when GUI vs CLI approaches are appropriate
