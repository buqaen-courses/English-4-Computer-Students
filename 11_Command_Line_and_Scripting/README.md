# Command Line & Scripting: Terminal Superpowers

**Course Theme:** From Novice to Automation Ninja

**Short Description:**
Master the command line and scripting to transform from GUI-dependent user to terminal power user. Learn to automate repetitive tasks, troubleshoot system issues, and build efficient workflows that scale from personal scripts to production automation.

**Learning Outcomes:**
- Navigate and manipulate files/directories efficiently using command-line tools
- Write maintainable shell scripts with proper error handling and documentation
- Use Git effectively for version control and collaboration workflows
- Apply command-line tools for system monitoring, networking, and troubleshooting

**Sample Activities:**
- **Command Line Challenge:** Navigate complex directory structures and perform bulk file operations
- **Scripting Workshop:** Build automated backup and monitoring scripts with comprehensive error handling
- **Git Workflow Mastery:** Practice branching, merging, and collaborative development patterns
- **System Administration Lab:** Monitor processes, manage services, and troubleshoot network issues

**Suggested Resources:**
- "The Linux Command Line" by William Shotts (comprehensive free guide)
- "Bash Cookbook" for practical scripting examples
- Git documentation and interactive tutorials
- tldr (simplified command documentation)
