# AI/ML Mastery Quiz

**Foundational Concepts:**

1. **Learning Types:** You're building an AI system to categorize customer support tickets. Would you use supervised, unsupervised, or reinforcement learning? Explain your choice and what data you'd need.

2. **Data Split Strategy:** You have 10,000 customer records for a churn prediction model. How would you split this data for training, validation, and testing? Why is this split important?

3. **Model Evaluation:** Your image classification model has 90% accuracy but only 60% precision. In the context of medical diagnosis, explain what this means and which metric you'd prioritize.

**Model Development Scenarios:**

4. **Algorithm Selection:** Compare using a decision tree vs. a neural network for predicting house prices. What are the advantages and disadvantages of each approach?

5. **Training Issues:** During model training, you notice validation loss increasing while training loss decreases. What problem is this indicating and how would you address it?

6. **Feature Engineering:** You're building a model to predict flight delays. What features would you create from raw flight data, and why would each be useful?

**Evaluation and Metrics:**

7. **Metrics Interpretation:** A fraud detection system has 95% precision but 75% recall. If false negatives (missed fraud) cost $10,000 each and false positives (false alarms) cost $100 to investigate, which metric should you optimize for?

8. **A/B Testing ML Models:** You have two recommendation algorithms. How would you design an A/B test to determine which performs better, considering both user engagement and business metrics?

9. **Model Calibration:** Your probability predictions are overconfident (predicting 90% when actual accuracy is 70%). How would you detect and fix this issue?

**Deep Learning Specifics:**

10. **Neural Network Architecture:** Explain the difference between convolutional layers and recurrent layers. When would you use each for processing different types of data?

11. **Training Dynamics:** Your neural network loss plateaus after 10 epochs. What techniques would you use to continue improving performance?

12. **Transfer Learning:** You want to build an image classifier for medical X-rays but have limited training data. How would you apply transfer learning to solve this problem?

**Ethics and Bias:**

13. **Bias Detection:** You're building a hiring AI that reviews resumes. What types of bias might affect the system, and how would you test for them?

14. **Fairness Metrics:** Compare demographic parity and equal opportunity fairness. When would you use each approach, and what are their limitations?

15. **AI Safety:** Your autonomous vehicle AI sometimes fails in heavy rain. How would you approach this safety concern from an AI development perspective?

**Production and Deployment:**

16. **Model Monitoring:** Once deployed, how would you monitor your ML model's performance in production? What metrics would you track and why?

17. **MLOps Pipeline:** Design a basic MLOps pipeline for a sentiment analysis service. What stages would it include and what tools might you use?

**Research and Paper Analysis:**

18. **Methodology Evaluation:** A research paper claims their new algorithm achieves 15% better accuracy than existing methods. What questions would you ask about their experimental setup?

19. **Reproducibility Assessment:** How would you evaluate whether a published ML result is reproducible? What factors would you consider?

**Real-World Applications:**

20. **Multimodal AI:** You're building an AI system to analyze customer feedback from text, images, and audio. How would you approach combining these different data types?

**Bonus - Strategic Thinking:**

21. **AI Product Strategy:** You're launching an AI-powered product. How would you balance model accuracy, inference speed, computational cost, and user experience in your design decisions?

22. **Career Development:** As someone studying AI/ML, what skills would you prioritize developing beyond technical knowledge? How would you demonstrate these skills to potential employers?
